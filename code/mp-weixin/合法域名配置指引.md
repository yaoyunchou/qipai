# 合法域名配置指引

配置已改好（`siteinfo.js`），本文档说明小程序后台还需配哪些域名。

## 一、本次改动

`siteinfo.js` 已从失效的 `hjsc.com` 换为新域名：

```js
module.exports = {
   acid: -1,
   version: "1.0.0",
   siteroot: "https://jd.jxfg.top",
   apiroot: "https://jd.jxfg.top/web/index.php?_mall_id=1"
};
```

**格式说明**：`apiroot` 末尾必须带 `?`（因为运行时拼接规则是 `apiroot + "&r=" + 接口路径`），
即最终请求为 `https://jd.jxfg.top/web/index.php?_mall_id=1&r=api/index/config`。
与原配置格式一致，无需改动写法。

## 二、小程序后台需配置的白名单

登录 mp.weixin.qq.com → **开发管理 → 开发设置 → 服务器域名**，逐项添加：

| 类别 | 填入值 | 说明 |
|---|---|---|
| **request 合法域名** | `https://jd.jxfg.top` | ⚠️ **必配**，接口请求域名 |
| **uploadFile 合法域名** | `https://jd.jxfg.top` | ⚠️ **必配**，商品图片上传（微信支付收款码、评价图片等） |
| **downloadFile 合法域名** | `https://jd.jxfg.top` | 建议配，用于文件下载 |
| **socket 合法域名** | 通常不需要 | 未使用 WebSocket 可不填 |

**注意**：后台只填**域名**，不带路径、不带 `https://` 后缀以外的任何内容。
填 `jd.jxfg.top`（部分后台要求不带协议头，按页面提示格式来）。

### 调试阶段可以先跳过
`project.config.json` 里 `urlCheck: false`，开发者工具本地调试**不校验域名**，
所以现在就能跑起来。但真机预览和上传发布**必须配白名单**，否则直接失败。

## 三、🔴 当前阻塞项：域名被腾讯云 DNSPod 封禁（2026-10-07 16:05 修正）

> **重要更正**：本节初稿写的是「443端口 TLS 握手失败，需服务器侧配置证书」，
> **该判断错误**。重新排查后确认真因是**域名被腾讯云封禁**。

**决定性证据**：
```
curl http://jd.jxfg.top/web/index.php?_mall_id=1&r=api/index/config
→ HTTP/1.1 302 OK
→ Location: https://dnspod.qcloud.com/static/webblock.html?d=jd.jxfg.top
```
**任意路径**（`/`、`/anything/test` 等）都 302 到同一 webblock 页，
这是腾讯云 DNSPod 的**域名封堵页**——说明域名在腾讯云侧被违规封禁。

**为何表象是"证书问题"**（容易误判的坑）：
- 80 端口有响应（302）
- **443 端口一个字节都不返回，直接 RST连接**

所以 curl报`failed to receive handshake` / `WinError 10054`，
很容易误判成"证书没配"。**实际是域名被封后443 服务根本不存在。**

📌 **排查教训**：遇到 TLS 握手失败，**必须同时测 80 端口**。
若 80 有响应而 443 完全无响应，问题在封堵/防火墙层，不在证书层。

### 浏览器为什么"能打开"
浏览器会**自动跟随 302** 跳到 `dnspod.qcloud.com/static/webblock.html`，
用户看到的是一个**能正常显示的拦截提示页**，于是以为"站点能访问"。
但小程序要的是 JSON，拿到的当然是 HTML → `code` 为 undefined → 首页白屏。

⚠️ 典型的**「浏览器能开≠ 接口可用」**陷阱。

### 排查矩阵（可直接复用）
| 测试方式 | 结果 |
|---|---|
| curl 走系统代理 | HTTP 000 |
| curl `--noproxy "*"` 直连 443 | exit 35 握手失败 |
| curl `--tlsv1.2 --tls-max 1.2` | 仍失败（排除协议协商问题）|
| curl `--http1.1` | 仍失败 |
| Python urllib 忽略证书校验 | RemoteDisconnected |
| **curl 80 端口** | **302 → dnspod webblock（决定性）** |

### 需要域名侧处理（前端无法绕过）
1. 登录腾讯云控制台查该域名的状态，确认是**未备案**还是**违规封禁**
2. 未备案 → 完成 ICP 备案后绑定国内主机
3. 违规封禁 → 需向腾讯云申诉解封
4. 若换新域名：注意同主体/备案问题会复发

⚠️ **额外提醒**：项目名`zjhj_bd_app`（棋牌）。国内主体经营棋牌类业务
涉及**版号与合规红线**，这可能正是域名被封的原因，也可能是小程序审核的阻碍。
建议尽早核实相关资质。

## 四、临时绕过方案（仅供本地调试）

若急着看页面效果，可临时用 HTTP 直连，**但仅限开发者工具本地调试**
（`urlCheck: false` 时 http 也能跑）：

```js
module.exports = {
   acid: -1,
   version: "1.0.0",
   siteroot: "http://jd.jxfg.top",
   apiroot: "http://jd.jxfg.top/web/index.php?_mall_id=1"
};
```

⚠️ **正式发布必须换回 https**，微信强制要求，且 http 域名无法加入合法域名白名单。
